# Световой модуль на WS2815

Скетч для Arduino Nano V3: стоп-сигналы, поворотники, габариты, задний ход
и индикация багажника на ленте WS2815 из 144 диодов (DATA на D11, FastLED).

Файл: [`light.ino`](light.ino). Папка и скетч называются одинаково, поэтому
Arduino IDE открывает его двойным щелчком.

## Что проверено

`test/run.sh` собирает скетч обычным `g++` с заглушками вместо FastLED, EEPROM
и Arduino и прогоняет 68 проверок: по каждому условию ТЗ сверяются номера
диодов, порядок шагов заполнения и гашения, цвета, приоритеты и режим
калибровки. Лента при этом симулируется массивом, железо не нужно.

```
cd light/test && ./run.sh
```

## Что исправлено против прошлой версии скетча

| Что было | Что стало |
| --- | --- |
| Номера диодов из ТЗ (1..144) подставлены в массив как есть | Везде пересчитаны в индексы 0..143. Группы багажника и границы половин в условиях 11/12 были смещены на один диод |
| Условия 4, 6 — мгновенная заливка всей ленты с плавным разгоранием яркости | Настоящее заполнение по диапазонам из ТЗ: габариты из середины к краям, стоп — четырьмя проходами сразу |
| Условия 5, 7, 9 — гашение общим затуханием яркости | Гашение бегущим фронтом по диапазонам ТЗ, у каждого условия свой рисунок |
| Условие 8 перезапускало заполнение по кругу | Заполнение проходит один раз, дальше лента просто горит белым |
| `COLOR_ORDER RGB` | `GRB` — штатный порядок для WS2815 |
| Калибровка могла зависнуть навсегда на `while (digitalRead(...))` | Таймауты на каждом ожидании, антидребезг, отказ показывается красным, старая калибровка при этом не теряется |
| Калибровка могла пропустить начало следующего импульса во время синей вспышки | Во время вспышки вход продолжает опрашиваться |
| В EEPROM писалось «сырое» число | Запись с меткой и контрольной суммой: мусор в EEPROM больше не принимается за настройку |
| Лента замирала, пока держится кнопка калибровки | Эффекты работают, пока не набежали 4 секунды |
| `FastLED.show()` вызывался каждый проход цикла | Только когда картинка изменилась |

Сверх ТЗ добавлены две вещи, обе отключаются одной строкой:

- **Антидребезг входов** — `INPUT_DEBOUNCE_MS = 15`. Контакты реле и
  концевиков дребезжат, помеха на 12 В линии иначе даёт вспышку ленты.
  Поставьте `0`, чтобы читать входы без задержки.
- **Тормоз прерывает калибровку.** Калибровка блокирует ленту, поэтому
  нажатие на педаль выходит из неё немедленно.

## Расхождения в самом ТЗ — нужно решение

1. **Багажник, D6.** В разделе «Входы» — «управление: низкий уровень»,
   в Условии 5.1 — «Если Pin 6 = HIGH». Принят **LOW**, как у остальных
   входов: при `INPUT_PULLUP` неподключённый вход всегда читается как HIGH,
   то есть вариант «HIGH» означал бы непрерывное мигание жёлтым при закрытом
   багажнике. Вернуть букву ТЗ: `#define TRUNK_ACTIVE_LEVEL HIGH`.

2. **Условие 7, гашение стопа.** В ТЗ «гасить 144-73, 0-36»: диоды 37..72
   не гасятся вообще, а два прохода разной длины (72 и 36 диодов) закончились
   бы в разное время. Реализовано «144-73 и 1-72» — два прохода от краёв
   к середине, лента гаснет полностью. Рисунок задаётся в `PAT_ENDS`.

3. **Приоритет при нескольких сигналах сразу.** В ТЗ задан только для
   «стоп + задний ход» (Условие 10). Принято:
   стоп → задний ход с поворотом → задний ход → аварийка → поворот →
   багажник → габариты → выключено. Тормоз всегда важнее остального.

4. **Условие 13, что именно измеряем.** В ТЗ рядом стоят «время между началом
   и концом сигнала» (это длительность импульса) и «средний интервал между
   сигналами» (это период). Измеряются и сохраняются оба, но время заполнения
   считается от **длительности импульса**: заполнение должно успеть пройти,
   пока штатный поворотник горит, иначе эффект обрывается на середине.
   Доля импульса под заполнение — `turnFillPercent`, по умолчанию 90%.

## Настройка

Все параметры собраны в начале `light.ino`, менять прошивку в других местах
не нужно. Время задаётся не «мс на шаг», а «мс на весь проход» — не зависит
от того, сколько диодов берётся за один шаг.

| Параметр | Что задаёт |
| --- | --- |
| `turnColor`, `turnFillMs`, `turnStepLeds` | Поворотники и аварийка (усл. 1, 2, 3, 11, 12) |
| `turnFillPercent` | Какую долю импульса занимает заполнение после калибровки |
| `gabaritColor`, `gabaritBrightness`, `gabaritFillMs`, `gabaritOffMs` | Габариты (усл. 4, 5) |
| `trunkColor`, `trunkBlinkOnMs`, `trunkBlinkOffMs`, `trunkBlinkTimes` | Багажник (усл. 5.1) |
| `trunkGroup1`, `trunkGroup2` | Какие диоды входят в группы багажника |
| `brakeColor`, `brakeFillMs`, `brakeOffMs` | Стоп (усл. 6, 7, 10) |
| `reverseColor`, `reverseFillMs`, `reverseOffMs` | Задний ход (усл. 8, 9) |
| `COLOR_ORDER` | Порядок цветов ленты, если красный и зелёный перепутаны |

## Калибровка (условие 13)

Удержать кнопку на D2 четыре секунды. Лента мигает зелёным и ждёт первый
сигнал на D3. Дальше на каждый из четырёх импульсов поворотника лента мигает
синим ровно на длину импульса. В конце — пять белых вспышек за две секунды,
результат записан в EEPROM и применён к условиям 1, 2, 3, 11, 12.

Если сигнала нет полминуты, или нажат тормоз — три красные вспышки и выход,
прежняя настройка остаётся.
